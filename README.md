# Loot Shooter Framework

Loot Shooter Framework is a reusable multiplayer gameplay framework for Unity.

The framework is designed for cooperative third-person shooter RPGs and focuses on scalability, modularity, and clean architecture.

## Goals

- Multiplayer First
- Server Authority
- Reusable Framework
- Package-based Development
- Clean Architecture
- High Performance

## Features

Current

- NGO Multiplayer Foundation

Planned

- Networking Framework
- Character Framework
- Camera Framework
- Combat Framework
- Inventory Framework
- Interaction Framework
- Gameplay Framework

## Architecture

The framework will gradually evolve into a Domain-Driven Design (DDD) and Hexagonal Architecture.

During the early networking stages, simplicity is prioritized while validating gameplay concepts.

## Target Game

- Third Person Shooter RPG
- Cooperative Multiplayer
- Up to 6 Players
- Steam Integration
- Host-Client Architecture
